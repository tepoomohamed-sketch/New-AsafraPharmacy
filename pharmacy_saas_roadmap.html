✅ المطلوب للـ SaaS
  • Multi-tenant Firestore (pharmacy per collection)
  • Self-service signup + trial تلقائي
  • نظام اشتراك (Paymob / Fawry)
  • Super-admin dashboard لإدارة العملاء
  • Custom subdomain لكل صيدلية
🗄 هيكل Firestore الجديد (Multi-tenant)
pharmacies / {pharmacyId} / ← tenant root
    entries / {entryId}
    pos_sales / {saleId}
    attendance / {recordId}
    meta / balance
    meta / attendanceRates

subscriptions / {pharmacyId} / ← billing
    plan: 'basic'|'pro'|'enterprise'
    status: 'trial'|'active'|'expired'
    trialEnd: timestamp
